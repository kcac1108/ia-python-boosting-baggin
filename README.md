# IA & Machine Learning: Atividade de Laboratório (Bagging e Boosting)

## Contexto da Aula

Este notebook foi desenvolvido como parte das aulas práticas de Inteligência Artificial e Machine Learning. O material aborda conceitos fundamentais de técnicas de ensemble learning, explorando algoritmos avançados de classificação supervisionada como **Bagging** e **Boosting** usando dados do renomado dataset *Penguins*.

## Atividade Desenvolvida (LAB)

A atividade proposta sob a diretriz **"IA ML Atividade"** consistiu em realizar experimentos de laboratório prático, explorando o potencial de métodos de ensemble learning para melhorar a performance de modelos de classificação.

### Detalhes do Projeto:

- **Equipe:** Atividade realizada em dupla - João Avila e Kauã Cavalheiro.
- **Dataset Escolhido:** *Penguins* (obtido diretamente do repositório oficial da biblioteca Vega).
- **Técnicas Abordadas:** Implementação e comparação de **Bagging** e **Boosting** para classificação de espécies de pinguins.
- **Objetivo:** Realizar o pré-processamento e limpeza de dados, codificar variáveis categóricas, dividir o conjunto em dados de treino e teste, implementar modelos de Bagging e Boosting, ajustar hiperparâmetros, avaliar as métricas de performance (acurácia, matriz de confusão, precisão, recall, curva ROC) e comparar a importância das características físicas dos pinguins entre os diferentes modelos.
